**☀️WeatherView**

A simple and responsive Weather Dashboard built using HTML, CSS, and JavaScript, that provides real-time weather updates for any city around the world. 
It displays detailed weather information including temperature, humidity, pressure, wind speed, and a weekly climate forecast.

**Features**

**Search by City** — Instantly get weather updates for any location.

**Current Weather Info** — Displays temperature, humidity, pressure, and wind speed.

**Sunrise & Sunset Timings** — Shows accurate sunrise and sunset times.

**Weather Conditions** — Includes icons and descriptions for better visualization.

**Weekly Forecast** — Provides a 3-day weather forecast with temperature and icons.

**Responsive UI** — Works smoothly on desktop and mobile devices.
